# Pengolahan Citra Digital - Rotasi & Flip Citra

Web sederhana untuk memenuhi tugas praktikum Pengolahan Citra Digital (PCD) proyek ini melakukan manipulasi piksel secara manual (RGBA) menggunakan HTML5 Canvas dan JavaScript untuk memutar (rotate) dan mencerminkan (flip) gambar.

Fitur Utama
- Rotate 90° (Putar Searah Jarum Jam)
- Rotate 180°
- Rotate 270°
- Flip Horizontal (Pencerminan Kiri-Kanan)
- Flip Vertical (Pencerminan Atas-Bawah)
- Simpan Gambar
- ampilan Tema Dusty Pink

Teknologi yang Digunakan
HTML5 & CSS3(Desain Antarmuka & Layout Canvas Dinamis)
JavaScript (Manipulasi Data Piksel Matriks Citra)
